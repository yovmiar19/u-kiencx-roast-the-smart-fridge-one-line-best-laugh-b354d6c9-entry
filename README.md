A smart fridge roasts its owner in a single line: the milk-expiry alert was ignored for three days, and now the cereal is full of curdled regret.

## Run

```sh
node main.ts
```

Writes the one-liner to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
